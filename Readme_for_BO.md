# This is the readme for [BO]evaluate.py

## First, cd into \Equilibrium_project

Then, run
```bash
python [BO]evaluate.py
```

Here, I assume the human policy is a fixed "yes, 0, -10". The evaluate() function takes 3 parameters, (1) the paramater of AI policy, (2) the length of episode to test the policy, (3) the human policy. The evaluate() function returns the reward.
